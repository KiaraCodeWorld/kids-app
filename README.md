# 🧠 Brain Quest

> Every child deserves to feel brilliant before breakfast.

A Django app delivering a daily 5-minute multi-subject learning ritual for curious kids ages 7–10 — math, vocabulary, spelling, idioms, and general knowledge in one guided adventure.

## Features

- **Math Challenge & Mental Math** — fun problems and lightning-fast quizzes by grade
- **Word Explorer & Vocabulary** — discover and master powerful new words
- **Spelling Bee** — hear it, spell it, win it (with audio)
- **Idiom Island** — what phrases *really* mean
- **Daily Discovery** — amazing facts every day
- **Flashcards** — review words and idioms you've saved, flashcard-style
- Instant feedback, hints, AI explanations, streaks, and a friendly mascot

## Run locally

1. Activate the virtual environment:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
2. Install requirements if needed:
   ```powershell
   pip install -r requirements.txt
   ```
3. Run the Django development server:
   ```powershell
   .venv\Scripts\python.exe manage.py runserver
   ```
4. Open http://127.0.0.1:8000/ in your browser.
